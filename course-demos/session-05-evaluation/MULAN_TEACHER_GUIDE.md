# 《木兰辞》同稿双评 · 教师说明

## 教学目标

本例对应 L4 的“区分要点覆盖率与摘要质量评分”。用熟悉的材料降低理解成本，固定原文和摘要，仅改变评估方法。没有写作练习，也没有生成模型调用。

两种方法使用同一模型，但评价上下文不同：覆盖率只看单项要点和摘要，综合评分还读取完整原文和任务。这是两套方法的对比，不是模型排名，也不是仅替换一个词的消融实验。

## 课前准备

原文采用[香港教育局《木兰诗》原文参考版本](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/ks3_08_text.pdf)，保留繁体与异体字，按原文分为六段。摘要使用现代简体中文。评价应理解语义，不做字面匹配。

打开 `fixtures/mulan_eval.json`，其中有完整原文、统一任务、五个要点和 A/B/C 三份摘要。可先只展示原文、要求和 B，暂不展示参考结果。

仓库根目录运行（Windows 建议使用已安装依赖的项目虚拟环境）：

```powershell
.venv/Scripts/python.exe course-demos/session-05-evaluation/compare_evaluators.py --mock --summary-id B
.venv/Scripts/python.exe course-demos/session-05-evaluation/compare_evaluators.py --mock
```

去掉 `--mock` 后，有 Key 则真实评分，没有 Key 则明确标注人工回放。真实模式需安装现有课程依赖中的模型 SDK。指定 B 只执行 B，仍核对完整输入指纹。

## 样例如何构造

- A：覆盖从军缘由、征战、受赏后的选择、返乡团聚与身份揭晓五项。
- B：完整保留 A，追加“返乡后，木兰与一位同行将领成婚。”五个正确要点都还在，错误是额外编造。
- C：只保留 A 的前两句，覆盖前两项，遗漏后三项；现有事实本身正确。

不能把 B 改成“留朝任官”，否则原有正确要点也可能失去，覆盖率随之下降，主对照不再清晰。

| 摘要 | 人工覆盖率参考 | 人工质量参考 | 要讲清楚的区别 |
|---|---|---|---|
| A | 100% | 5/5 | 完整且忠实 |
| B | 100% | 1/5 | 完整却新增无依据事实 |
| C | 40% | 2/5 | 正确却遗漏核心任务 |

这是人工参考矩阵。回放分数来自人工编写，真实模型不保证复现；不能择优展示多次运行。

## 15–20 分钟流程

1. **2–3 分钟**：读原文和统一摘要要求，明确五项要点。
2. **3 分钟**：展示 B，问“哪些内容正确？最后一句来自哪里？覆盖率会扣分吗？”先让学生预测。
3. **4–5 分钟**：同稿双评，展开逐点 HIT/MISS，再看综合评分的四项评语和证据。
4. **3–4 分钟**：展示 A/C，讨论 C 为何“没写错”仍不能得高分。对照矩阵，不换算共同百分制。
5. **3–5 分钟**：迁移回事故摘要：写到了根因、影响和待办，是否就保证没编造数字？只优化覆盖率会漏掉什么？

然后进入 Prompt A/B：本例固定输出、改变评价方法；下一实验固定评价方法、改变生成 Prompt。

## 读源码的位置

- `judge.evaluate_points()`：五个要点分别 YES/NO，汇总 coverage；复用旧逐点提问，新增严格解析。旧 `judge_point()` 的英文 token-overlap fallback 不用于中文 Demo。
- `judge_google.evaluate_summary()`：共享的单摘要评分与引文检查；与旧事故入口使用同一评分函数和模板。
- `compare_evaluators.evaluate()`：从一个输入对象取同一摘要，调用两条方法并保存报告。

覆盖率一份五次调用，综合评价一份一次调用；全套为 15 + 3 次应用层调用。客户端可能另行重试网络请求。temperature 均为 0，响应上限分别为 32 和 2200 tokens。

## 证据与异常的边界

原文 p05 写伙伴惊讶，p06 以双兔比喻收尾。全文没有交代婚恋结局。局部引文仅供定位，不能凭一处引文证明全文不存在某信息。

程序验证引文来自原文，不验证引文一定支持评语；仍需人工核查。若 Judge 意外给 B 高分，应照实讨论，不修改结果。

非法 YES/NO、JSON、引文或 API 失败是 `error/null`，不是 MISS 或 1 分。另一种方法继续执行，但不把缺失结果拿来比较。真实失败不会切换成人工答案。

修改摘要后，必须配置真实模型。离线回放绑定完整输入和两种规则，不能为改后的作品返回旧人工分数。
